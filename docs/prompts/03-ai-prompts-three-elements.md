## 検討メモ

方策プロンプトはすでに近い3条件を書いているが、文言が古い。

```
・自分で決められること
・結果が見えやすいこと
・周囲とゴールと進捗を共有できること
```

最初の一歩プロンプトには3要素が無い。ユーザー要望は **両方** に「自分で決められるか？」「成果が分かりやすいか？」「周りと繋がっているか？」を含めること。

Chrome AI は URL 長の制約があるので、02 の全箇条書きをそのまま貼らず、**問いの正式名＋短い充足条件** に圧縮する。JSON スキーマと件数（方策5 / 一歩10）は変えない。

## 正本の3要素（プロンプトに使う名前。言い換えない）

1. 自分で決められるか？
2. 成果が分かりやすいか？
3. 周りと繋がっているか？

英語プロンプトでも同じ意味で揃える:

1. Can you decide it yourself?
2. Can you see your results clearly?
3. Are you connected with others?

ベトナム語:

1. Bạn có thể tự quyết định không?
2. Bạn có thấy rõ thành quả không?
3. Bạn có kết nối với mọi người không?

## 推奨する日本語システムプロンプト差分

### 方策 `strategySystemPrompt`（japanese）

「なお方策は…をできるだけ満たしてください。」を次の趣旨に置き換える（導入文・JSON スキーマ・件数ルールは維持）:

```
なお方策は、内発的動機づけの３要素をできるだけ満たしてください。
１．自分で決められるか？ — やり方を自分で決め、主導権が自分にあり、言われる前に動ける
２．成果が分かりやすいか？ — 成長や能力発揮を実感でき、粒度が細かく結果が見える（小さなくるくる）
３．周りと繋がっているか？ — ビジョン・ゴール・進捗を共有でき、サポートを得られ、役に立ち当てにされる（唱って躍れる）
```

en / vi も同じ3点。キーワード（小さなくるくる / 唱って躍れる）は ja のみでよい。en/vi は意味の短文だけでよい。

### 最初の一歩 `firstStepSystemPrompt`（japanese）

30分以内・明日から・10件のルールは維持したまま、ルールに1項目足す:

```
- 各行動は内発的動機づけの３要素「自分で決められるか？」「成果が分かりやすいか？」「周りと繋がっているか？」をできるだけ満たす
```

en/vi も同じ3問いを入れる。最初の一歩は粒度が小さいので、方策ほどの長文説明は不要。

## Step 1 — 方策プロンプト

### 目的

AI の方策案が新しい3要素を意識する。

### 指示

1. `PromptLibrary.strategySystemPrompt` の ja/en/vi を更新
2. `StrategySuggestion` のコメントを新しい3要素名に直す
3. `test/strategy/strategy_flow_screen_test.dart` の `contains('自分で決められること')` を新しい文言に合わせる。3問いすべてがプロンプトに含まれることを assert する
4. プロンプト単体を直接テストするなら `test/engine/` に薄いテストを足してよい。必須ではない

### 受け入れ

- [ ] 送信プロンプトに3つの正式な問いがある（ja。en/vi も対応訳）
- [ ] 旧「結果が見えやすいこと」「周囲とゴールと進捗を共有できること」だけに頼っていない
- [ ] strategies は5件、JSON only の指示が残っている
- [ ] 当該テストが通る
