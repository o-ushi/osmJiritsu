# ユーザーズマニュアルの自動翻訳（Google Apps Script）

日本語マスターを直す → メニューから実行 → **同じ**英語版・ベトナム語版ファイルの中身が最新になる。  
ファイルの URL（ID）は変わらないので、アプリのヘルプリンクはそのまま使える。

対象ファイル:

| 言語 | 役割 | ファイル ID |
| --- | --- | --- |
| 日本語 | マスター（ここだけ手で直す） | `1C3BGFdWm6UneFcPQC0d7ftQ46n65hsN4uB8KAdXHObU` |
| 英語 | 上書き更新（新規コピーしない） | `14pVMbXOI4YSaV-PpC02N1r6IYFNTYUFiqcdiIA5uLos` |
| ベトナム語 | 上書き更新（新規コピーしない） | `1ALuMLxX3wRoySWb6mWdY8i59eLeP7gy-O7Ut5q8elFc` |

## 初回セットアップ（1回だけ）

1. **日本語マスター**の Google スライドを開く。
2. メニュー **拡張機能 → Apps Script** を開く。
3. エディタに `コード.gs`（名前は `Code`）があるので、リポジトリの `docs/user-manual-gas/Code.gs` の中身をすべて貼り付ける。
4. 左の **+** → **スクリプト** でファイルを追加し、名前を `Glossary` にする。  
   `docs/user-manual-gas/Glossary.gs` の中身を貼り付ける。
5. ディスクアイコンで保存する。
6. スライドのタブに戻り、**再読み込み**する。  
   メニューに **マニュアル翻訳** が出る。

## 毎回の使い方

1. 日本語マスターを直して保存する。
2. **マニュアル翻訳 → 英語とベトナム語を両方更新**（または片方だけ）。
3. 初回だけ「権限を確認」と出る。自分の Google アカウントで許可する。  
   （スライドの閲覧・編集と、Google 翻訳の利用）
4. 終わると件数がダイアログに出る。
5. 英語版・ベトナム語版を開き、はみ出した文だけ直す。

## ハイパーリンク

他のスライドファイルへコピーすると、青字・下線は残っても**飛び先が日本語マスターのスライド ID のまま**になる。クリックしても反応しないのはそのため（今朝の変更以前から同じ）。

スクリプトは日本語マスター上で「何枚目へ飛ぶか」を記録し、翻訳後に英語・ベトナム語ファイルの**同じ番号のスライド**へ `setLinkSlide` で付け直す。  
索引のタブ揃えは区切りを消さずに日本語だけ訳す。

## 表の余分な改行

Google 翻訳は表セルの途中に折り返し用の改行を入れることがある。  
スクリプトは **元の日本語セルと同じ行数** に戻し、増えた改行は空白にする。  
意図した改行（日本語マスターで既に2行以上あるセル）はその行数を維持する。

英語版・ベトナム語版のファイルは **消さない・コピーし直さない**。消すと ID が変わり、アプリから飛べなくなる。

## うまくいかないとき

- メニューが出ない → マスターのスライドを再読み込み。スクリプトはマスターに紐づける。
- 権限エラー → 3ファイルとも、この Google アカウントが編集できること。
- 途中で止まる・一部だけ日本語のまま → 無料の Google 翻訳には **1日あたりの文字数上限**がある。翌日もう一度同じメニューを実行する（同じ文は辞書優先なので再実行してよい）。
- 英語・ベトナム語が開けない（アプリから） → 各ファイルの共有を「リンクを知っている全員（閲覧可）」にする。

## 翻訳の優先順位

1. `Glossary.gs` の用語辞書（アプリの画面文言と揃える）
2. 辞書に無い文だけ Google 翻訳
3. 日本語が無い枠（番号、osmJiritsu など）はそのまま
